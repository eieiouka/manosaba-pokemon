# 自己対戦学習

Node.js 24以上で動作。外部AI APIやGPU、追加のnpmパッケージは不要。

## 学習（PowerShell）

```powershell
node scripts/train-ai.mjs --games 1000000 --workers 8 --out analysis/value.json
```

最初に小規模で試すなら --games 10000。出力ファイルは毎バッチ更新され、Ctrl+Cで止めても、同じコマンドで再開できる。--games は累計目標なので、100万戦完了後は --games 10000000 で1000万戦まで続けられる。学習設定や対戦エンジン変更時は別の --out を指定する。

## 構築探索で使用

```powershell
node scripts/solve-teams.mjs --shortlist analysis/screen.json --top 10 --model analysis/value.json --depth 2 --beam 3 --opponents 8 --repeats 4 --workers 8 --out analysis/deep-learned.json
```

--model で学習済み評価を使用する。--quick は学習済み評価を使わないため併用不可。学習モデルのキャラクター性能は学習時と同じものを使用する。学習結果はローカルのファイルに保存され、公開版CPUに自動反映されるわけではない。

## 学習内容

- 13人から双方の3人選出をランダム生成し、実際の対戦エンジンで自己対戦。
- 現行の評価関数、キャラごとの生存・HP・能力ランク・状態異常・持ち物・PP、味方の組み合わせ、対面、場の効果など503特徴量を使用。
- 終局の勝敗を教師信号として、線形の勝率予測器を更新。引き分けは0.5勝相当。
- 毎バッチで最新モデルを使って候補行動を1ターン先まで試し、従来の簡易AIや探索行動も混ぜる。未知の行動を試すためのランダム選択も含む。
- 学習後の評価は未学習の乱数を使い、モデルを使うAIと従来の簡易AIを比較する。--eval 5000 などで試行数を増やせる。学習とは別の評価であり、学習量に比例して必ず強くなるとは限らない。
- オフライン学習・評価中は双方の3人選出を既知として扱う。完全情報・有限探索の近似で、厳密な最適戦略やニューラルネットワークのAlphaZero実装ではない。

## オプション

--workers: 並列数
--batch: 1ワーカーあたりの更新間隔
--epsilon: 学習中にランダム行動する確率（既定0.15）
--learned-rate: 学習済み評価を使用する割合（既定0.5）
--candidates: 1ターン先読みする候補数（0なら全合法手、既定3）
--samples: 1ターン先読み時の乱数サンプル数
--policy quick: 従来の簡易AIだけで訓練（高速だが方策改善なし）
--eval: 学習終了後の評価戦数（既定200、0で省略）
